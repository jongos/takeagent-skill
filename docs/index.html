Can I Use It Without an Account?

Yes, for educational guidance from your AI assistant. That is host assistance, not an anonymous TakeAgent service call. The current Free service requires website sign-in and does not include MCP access.

What if I Forget to Sign In?

The skill checks your connection before account work and gives a short login reminder if you are signed out. After connecting, it checks your actual plan and permissions. It never assumes you need an upgrade just because you forgot to log in.

Does the Skill Include a Paid Membership?

No. Connected tools follow your current TakeAgent plan, permissions and usage limits. EP is the basic paid tier for connected use; check enrollment availability in TakeAgent. Selecting a tier does not itself activate access.

Can It Edit and Save My Projects?

With the required consent, discovered tools can save named draft proposals without changing working rows. The skill guides you to TakeAgent’s website for working-project edits, importing, applying plan changes and exporting. It does not claim to complete a change until it is verified.

Does It Work in Every AI App?

There is no universal installer. Claude and compatible MCP clients have connection paths; Gemini CLI support does not establish Gemini app support. Capable Grok Bot hosts can install the skill and an OAuth MCP connector; other Grok surfaces are guidance-only. Follow the setup guide for your surface.
